# ✨ Glassy Dashboard

A modern glassmorphism-powered **Chrome New Tab Extension** that transforms your browser into a beautiful, customizable dashboard.

## ✨ Features

### 🧑‍💻 Dashboard
- 🕒 Live Clock
- 🎨 Glassmorphism UI
- 🌓 Light & Dark Theme
- ⚡ Fast & Lightweight
- 💾 Local Storage

### 🔖 Bookmarks
- 📂 Folder-based bookmark manager
- 🔍 Instant bookmark search
- 🗑️ Delete bookmarks
- ⭐ Quick access to favorites

### 🚀 More
- 🖼️ Custom Background
- 📌 Frequently Visited Sites
- 🔒 Runs locally using Chrome Extension APIs

---

## 📦 Installation

1. Download the latest release from **Releases**.
2. Extract the ZIP file.
3. Open `chrome://extensions`.
4. Enable **Developer Mode**.
5. Click **Load unpacked**.
6. Select the extracted `dist` folder.
